# サンレンタン

出題者の価値観をみんなで当てるパーティーゲーム「サンレンタン」を、スマホのブラウザで P2P 対戦できる Web アプリです。

## 遊び方
- ホストが「部屋をつくる」→ 5文字の部屋コード（または招待リンク）を共有
- 他の人は「参加」でコードを入力、またはリンクを開く（2〜12人）
- ホストがドボンあり/なし・ラウンド数を設定して開始
- 出題者はお題を3つの候補から選び、A〜G から 1〜3位（＋ドボン）を選択。回答者は同時に予想
- 回答者3位→2位→1位→出題者3位→2位→1位→ドボンの順に、出題者がボタンで1つずつ公開
- 全員が1回ずつ出題して1ラウンド。指定ラウンド終了で最終順位を発表

| 役 | 条件 | 点 |
|---|---|---|
| サンレンタン | 1〜3位すべて順位まで一致 | 6 |
| サンレンプク | 1〜3位すべて一致（順位不問） | 4 |
| ニレンタン | 1位・2位が順位まで一致 | 3 |
| プクプク | 2つ一致（順位不問） | 2 |
| タン | 1位が順位まで一致 | 1 |
| ドボン | 予想にドボンが入っている | −1 |

## 開発
```
npm install
npm run dev     # スマホからは http://<PCのIP>:5173
npm run build   # dist/ を静的ホスティングへ
npm test
```
お題は `src/topics.js` に追加できます（1お題につき候補7つ）。

## 通信について
- ホスト端末が進行役となり、各プレイヤーと WebRTC で直接つながります（シグナリングのみ PeerJS 公開ブローカー）。
- ホストがブラウザを閉じると部屋は解散します。ゲストは通信が切れても自動で再接続し、同じ席に戻れます。
- 切断したままのプレイヤーはホストが「除外」できます。
- 厳しい NAT 環境では `VITE_TURN_URL` / `VITE_TURN_USER` / `VITE_TURN_PASS` を設定して TURN を使ってください。
